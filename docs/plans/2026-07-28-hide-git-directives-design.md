# 隐藏 Git 界面指令设计

## 目标

Codex Desktop 会在 AI 最终回复中附加 `::git-*{...}` 界面指令。移动端目前将这些指令作为普通 Markdown 文本展示，影响阅读。

页面应只展示面向用户的回复正文，不展示独立成行的 Git 界面指令。

## 展示规则

- 只过滤 AI 消息，不处理用户消息。
- 只隐藏独立成行且格式完整的 `::git-*{...}` 指令。
- 支持 `git-stage`、`git-commit`、`git-create-branch`、`git-push`、`git-create-pr` 及后续同格式 Git 指令。
- 正文内出现的 `::git` 字样继续展示。
- Markdown 围栏代码块中的指令示例继续展示。
- 过滤完成后清理因指令产生的末尾多余空行。

## 数据边界

过滤只发生在 AI 消息的展示层。app-server 返回的原始会话、实时事件和本地状态均保持不变。

## 验证

- 单元测试覆盖单条和连续多条 Git 指令。
- 单元测试覆盖普通正文和围栏代码块不被误删。
- 组件测试确认 AI 消息隐藏指令而保留正文。
- 运行类型检查和生产构建，并在本机 dev 验证。
