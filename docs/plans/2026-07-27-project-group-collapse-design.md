# 项目分组折叠设计

## 目标

单机视图中的项目标题整行支持点击折叠或展开，并在本机保存各机器、各项目的状态。

## 交互

- 项目默认展开。
- 点击项目标题整行切换展开状态。
- 展开时显示打开的文件夹图标；折叠时显示关闭的文件夹图标。
- 折叠后隐藏该项目的会话和“展开显示”按钮。
- 重新展开时保留此前已经展开的会话条数。
- 搜索期间临时展开包含匹配结果的项目；清空搜索后恢复缓存状态。

## 状态与缓存

- 使用 `backendId + cwd` 生成项目状态键，避免不同机器的同名目录互相影响。
- 折叠项目键数组写入 `localStorage` 的 `codex-mobile:collapsed-projects`。
- 缓存损坏或不是字符串数组时按空集合处理，即全部项目展开。

## 可访问性

- 项目标题使用按钮实现整行点击。
- 使用 `aria-expanded` 暴露当前实际显示状态。

## 验证

- 测试展开和折叠时的会话、加载更多按钮及文件夹图标。
- 测试搜索期间临时展开，清空搜索后恢复折叠。
- 测试缓存读取、写入和异常数据兼容。
- 运行全部相关单元测试、类型检查和构建。
