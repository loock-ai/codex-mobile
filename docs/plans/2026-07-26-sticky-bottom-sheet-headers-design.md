# 底部弹框标题吸顶设计

日期：2026-07-26

## 目标

所有带标题的移动端底部 Sheet 在内容滚动时，标题与关闭、更多或下载操作保持
可见。顶部横条已移除，避免占用额外高度和产生不可拖拽的视觉暗示。

## 统一规则

- 工具详情、文件 Diff、远程图片文件和远程文本文件使用同一标题吸顶规则。
- 标题栏相对各自 Sheet 的滚动容器 `position: sticky; top: 0`。
- 标题栏使用与 Sheet 一致的不透明背景和较高层级，滚动内容不能透出。
- 标题栏保留原有按钮至少 44px 的点击区域。
- 只有弹框内部滚动，底层会话位置保持不变。
- 远程文本文件的代码区已是独立滚动容器，标题仍声明 sticky，保持规则一致。

## 测试

- 移动端 E2E 将工具详情滚动到底，验证标题栏纵坐标不变。
- 文件 Diff、远程图片和远程文本标题栏均验证 sticky 与 `top: 0`。
- 验证弹框内部滚动不会产生页面横向溢出。
