# 对话详情顶部按钮紧凑设计

## 目标

缩小对话详情顶部的侧边栏、上下文占用和会话菜单三个按钮，减少 Header 的视觉重量。

## 尺寸

- 三个按钮统一由 `50px` 调整为 `44px`。
- 普通按钮图标由 `26px` 调整为 `23px`。
- 上下文占用圆环外径由 `25px` 调整为 `22px`，内径和中心点同比缩小。
- 对话详情 Header 最小高度由 `68px` 调整为 `60px`。
- Header 列宽和间距同步收紧。

## 边界

- 只影响对话详情页。
- 会话列表顶部刷新和菜单按钮保持现有尺寸。
- 按钮功能、可访问名称和点击逻辑不变。

## 验证

- 样式测试确认对话详情三个按钮均为 `44px`。
- 样式测试确认普通图标为 `23px`、Header 为 `60px`。
- 运行完整测试、类型检查和生产构建。
