# 移除会话悬浮向下箭头设计

日期：2026-07-28

## 目标

移除会话详情右下角的黑色悬浮向下箭头，避免遮挡历史分页入口和输入区域。

## 范围

- 删除 `ConversationPage` 中的悬浮按钮。
- 删除只为控制该按钮显示而存在的 `showJumpToLatest` 状态。
- 删除 `.jump-to-latest` 样式。
- 保留首次进入会话自动滚动到底部、跟随实时内容，以及用户上滑后暂停跟随的行为。

## 验证

- 页面不再渲染“回到最新消息”按钮。
- 内容增长时仍会自动跟随底部。
- 用户上滑后内容增长不改变当前阅读位置。
- 会话详情分页、输入框和实时消息测试保持通过。
