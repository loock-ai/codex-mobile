# 侧边栏打开刷新与“全部”列表视觉优化设计

## 目标

- 移除项目、会话列表和相对时间文案的 60 秒定时刷新。
- 侧边栏每次从关闭变为打开时，刷新所有已启用机器。
- 保留右上角手动刷新，并在刷新期间展示旋转动效。
- 优化“全部”视图的来源信息和“全部”Tab 尺寸。

## 刷新逻辑

应用首次加载仍由各机器连接成功后的既有流程获取项目和会话，不额外触发一次刷新。

侧边栏只有发生“关闭到打开”的状态变化时才触发刷新。刷新会：

1. 请求所有已启用机器的 `/api/projects`；
2. 使用最新项目目录加载各项目会话；
3. 重置项目“展开更多”的临时显示条数；
4. 重新渲染当前列表。

侧边栏已经打开时，重复调用打开操作不会发起请求。右上角手动刷新与侧边栏打开共用同一个刷新入口。

## 时间显示

删除只为更新“几分钟前”而存在的 60 秒计时器。列表每次渲染时直接以当前时间计算相对时间。侧边栏打开、手动刷新、会话事件和其他状态变化都会自然触发重新计算；页面静止时不产生后台定时工作。

## 刷新反馈

每台机器在处理统一刷新请求时记录独立的刷新状态。只要还有任意已启用机器未完成，右上角刷新图标就持续旋转；所有机器成功或失败后停止。

单独展开项目时的加载状态不计入全局刷新状态，避免刷新按钮出现误导性动画。

## “全部”视图

- 第一行继续展示会话标题及时间、未读或运行状态。
- 第二行只展示“机器名 · 项目名”，右对齐并移除绿色在线圆点。
- 蓝色未读点与运行中 Loading 保持不变。
- 单机项目分组视图保持现状。
- “全部”Tab 单独缩小至约 38px 高、12px 字号；机器 Tab 继续使用现有 44px 尺寸。

## 测试

- 不再注册会话列表与时间文案的 60 秒定时器。
- 侧边栏从关闭到打开时只触发一次所有机器刷新。
- 已打开状态下重复打开不刷新。
- 手动刷新继续触发相同刷新入口。
- 全局刷新期间按钮旋转，全部完成或失败后停止。
- 展开单个项目不会触发全局刷新动画。
- “全部”来源行右对齐且不包含绿色状态点。
- “全部”Tab 使用独立的紧凑尺寸。
