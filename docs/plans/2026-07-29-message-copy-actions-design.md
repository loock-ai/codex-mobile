# AI 消息与代码块复制设计

## 目标

- 为 Markdown 代码块增加独立复制按钮。
- 为每个已完成回合的最终 AI 消息增加一个消息级复制按钮。
- 消息级复制范围随“之前的消息”折叠状态变化，并始终输出纯文本。

## 消息级复制

每个已完成回合只在最终 AI 消息下方显示一个复制按钮。运行中的流式回复不显示复制按钮，完成后才出现。

复制范围以当前回合实际可见的 AI 文本为准：

- “之前的消息”折叠时，只复制最终 AI 回复；
- “之前的消息”展开时，复制该回合全部可见 AI 文本；
- 多条文本按展示顺序使用空行分隔。

复制内容来自已渲染的 `.assistant-message .markdown-body` 文本，因此会自动去除 Markdown 标记。用户消息、思考过程、工具调用、代码变更卡片和界面标签不在选择范围内。

## 代码块复制

统一 Markdown 渲染器接管块级 `pre` 渲染，在代码块右上角增加复制按钮。按钮只复制代码节点的文本，不包含 Markdown 围栏和语言标记。行内代码不增加按钮。

## 剪贴板与反馈

实现可复用复制按钮和文本复制函数：

1. 优先调用 `navigator.clipboard.writeText`；
2. Clipboard API 不可用或失败时，回退到临时隐藏文本框和 `document.execCommand("copy")`；
3. 成功后短暂显示“已复制”反馈；
4. 两种方式都失败时显示“复制失败”；
5. 点击复制按钮不改变消息折叠状态，也不影响页面滚动。

## 测试

- 代码块按钮只复制代码正文。
- 行内代码不显示复制按钮。
- 已完成回合只在最终 AI 消息后显示一个消息级复制按钮。
- 折叠时只复制最终 AI 纯文本。
- 展开时复制全部可见 AI 文本，并排除用户消息、思考、工具调用和界面标签。
- Clipboard API 成功、失败回退和最终失败反馈均有覆盖。
