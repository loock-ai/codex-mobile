# 前端组件拆分实施计划

## 第一批：锁定特征与拆分时间线

1. 运行现有单元测试、类型检查、构建和 E2E，记录绿色基线。
2. 为公共标题和图标辅助函数增加单元测试。
3. 提取远程文件 Sheet、工具 Sheet、时间线和单轮消息组件。
4. 运行单元测试、类型检查和 E2E。

## 第二批：拆分页面

1. 提取 `ThreadListPage`，通过 props 接收会话、状态和回调。
2. 提取 `ConversationPage`，保留原 DOM、类名和输入行为。
3. `App` 只组装页面数据与动作。
4. 运行单元测试、类型检查和 E2E。

## 第三批：拆分覆盖层

1. 提取 `ApprovalSheet`。
2. 提取 `ComposerSettings`。
3. 清理 `App.tsx` 中不再使用的展示辅助函数和导入。
4. 运行格式检查范围内的 TypeScript、构建和完整 E2E。

## 最终验收

1. 独立代码审查检查 props 边界、重复逻辑和行为漂移。
2. 测试子代理运行自动化和手机尺寸浏览器回归。
3. 修复审查问题后再次运行完整测试。
4. 提交重构代码，不推送远端。
