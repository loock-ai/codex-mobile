# 会话状态标识与待审批通知位置设计

## 目标

- 未读会话的蓝点展示在右侧时间之前，不再占用标题区域。
- 进行中会话继续使用现有的“蓝点 + 旋转 Loading”状态。
- 待审批通知固定悬浮在页面顶部 Header 下方，避免软键盘弹出后遮挡输入区的模型和权限按钮。

## 会话列表状态

会话行右侧统一作为状态区域：

- 未读且未运行：显示“蓝点 + 时间”。
- 正在运行：显示“蓝点 + 旋转 Loading”，不显示时间。
- 普通会话：只显示时间。

运行状态优先于未读状态。会话运行结束且用户尚未查看时，恢复为“蓝点 + 时间”。

## 待审批通知

通知继续使用悬浮样式和现有点击切换机器的逻辑，但定位从输入框上方改为 Header 下方：

- 使用固定顶部定位，不参与消息内容布局。
- 距离顶部由 Header 高度和页面顶部安全区共同决定。
- 保持现有宽度、圆角、颜色和层级。
- 键盘弹出时位置不随可视区域底部变化。

该方案允许通知覆盖少量顶部内容，但不会遮挡输入框及其操作按钮。

## 验证

- 组件测试确认未读蓝点与时间位于同一个右侧容器。
- 样式测试确认待审批通知使用顶部定位且不再包含底部定位。
- 运行 UI 定向测试、TypeScript 类型检查和构建。
