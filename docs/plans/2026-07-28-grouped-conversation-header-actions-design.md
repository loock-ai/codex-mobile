# 对话详情右上角双按钮胶囊设计

## 目标

参考 Codex 原版界面，将对话详情右上角的“上下文占用”和“会话操作”两个入口放进同一个横向圆角容器，降低零散按钮带来的视觉重量。

## 视觉

- 外层使用约 `88 × 44px` 的浅灰色胶囊容器，圆角为 `22px`。
- 两个按钮分别占据 `44 × 44px` 的独立点击区域。
- 两个区域之间不显示分割线。
- 上下文圆环和三点图标沿用当前紧凑尺寸。
- 胶囊整体与标题、左侧侧边栏按钮保持垂直居中。

## 交互

- 左侧区域继续打开上下文状态面板。
- 右侧区域继续打开当前会话操作菜单。
- 打开其中一个面板时，继续关闭另一个面板。
- 按钮的可访问名称和展开状态保持不变。

## 边界

- 只调整对话详情页右上角。
- 左侧侧边栏按钮保持独立圆形。
- 会话列表顶部刷新和设备管理按钮不受影响。

## 验证

- 组件测试确认两个按钮位于同一个操作容器。
- 样式测试确认容器为 `88 × 44px`、无分割线，内部按钮背景透明。
- 运行完整测试、类型检查和生产构建，并验证本机 dev。
