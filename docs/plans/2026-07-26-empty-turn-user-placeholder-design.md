# 无用户消息回合渲染设计

## 背景

app-server 的部分历史回合不包含 `userMessage`。当前 `TurnCard` 会为这类回合
生成“Codex 回合”用户气泡，容易让用户误以为它是一条真实输入。

## 方案

- 只有 `groupTurnItems()` 返回真实用户消息时，才渲染 `.turn-user` 和
  `UserBubble`。
- 没有用户消息时，不显示占位文案或空白用户容器，直接展示该回合的 AI 消息、
  思考过程和工具调用。
- 保持运行中实时展示、完成后过程折叠、最终回复展示等既有逻辑不变。

## 测试

- 构造没有 `userMessage` 的回合，断言不存在“Codex 回合”和 `.turn-user`。
- 保留现有真实用户消息用例，确认正常用户气泡继续渲染。
- 运行完整单元测试、类型检查、生产构建和浏览器 E2E。
