# 移动端文件 Diff 面板设计

日期：2026-07-26

## 目标

参考 Codex Remote 移动端界面，把 `fileChange.changes` 从通用 JSON 详情改为
文件级 Diff 面板。所有文件名、增删统计和代码内容必须来自 app-server V2
返回的 `changes[].path`、`changes[].kind` 与 `changes[].diff`。

## 入口与结构

- 点击工具活动中的“已编辑 N 个文件”打开独立底部面板。
- 面板顶部显示“已更改 N 个文件”和关闭按钮。
- 每个文件行显示缩略路径、绿色新增数和红色删除数。
- 默认展开第一个文件，其余文件默认折叠；点击文件行可独立展开或收起。
- 文件较多时整个面板纵向滚动，不改变底层会话滚动位置。

## Diff 渲染

- 前端解析 unified diff，不引入桌面风格的第三方 Diff 组件。
- 解析 `@@ -旧起始,数量 +新起始,数量 @@`，为上下文、删除和新增行计算旧、新
  行号。
- 新增行使用浅绿色背景和绿色强调边，删除行使用浅红色背景和红色强调边，
  上下文行保持中性色。
- hunk 之间显示“未修改的上下文”提示；原始 diff 未包含可推导数量时显示
  “上下文”。
- 代码区域允许自身横向滚动，页面主体不得产生横向滚动条。
- diff 不完整或无法解析时按原始行安全回退，仍保留增删颜色和内容。

## 状态与异常

- 正在修改时仍可打开面板，并随 `item/fileChange/patchUpdated` 的最新
  `changes` 重新渲染。
- 没有 diff 的文件显示“暂无 Diff 内容”，不输出原始 JSON。
- 路径通过文本节点渲染，不执行 HTML。

## 测试

- 单元测试覆盖文件统计、hunk 行号、新增/删除/上下文分类和异常输入回退。
- 移动端 E2E 覆盖面板入口、文件数、增删统计、默认展开第一个文件、切换文件
  展开状态、关闭面板和页面无横向溢出。
