# 底部弹框标题贴顶设计

日期：2026-07-26

## 目标

所有带标题的底部弹框中，吸顶标题栏的背景从弹框圆角顶部开始完整覆盖。内容滚动
时不能透到标题上方，同时保持标题文字原有的视觉间距。

## 统一规则

- 工具详情、远程图片、远程文本和文件 Diff 使用同一规则。
- 弹框容器的 `padding-top` 设为 `0`，消除标题栏上方的透明滚动区域。
- 原本的 12px 顶部间距迁移到标题栏内部，不改变标题文字和操作按钮的位置。
- 标题栏继续使用不透明背景、`position: sticky; top: 0` 和现有层级。
- 弹框圆角、底部安全区、左右间距及关闭、下载操作保持不变。

## 测试

- 四类弹框打开后，标题栏顶部与弹框顶部的坐标差不得超过 1px。
- 工具详情滚动到底后，标题栏坐标仍保持不变。
- 页面不得产生横向溢出。
