# 移除底部弹框横条设计

日期：2026-07-26

## 目标

移除所有带标题底部弹框标题上方的拖拽横条，减少无实际拖拽能力的视觉暗示和
纵向占用，同时保持标题栏吸顶。

## 统一规则

- 工具详情、文件 Diff、远程图片和远程文本弹框不再渲染横条。
- 原有标题栏继续使用 `position: sticky; top: 0`。
- 工具详情与文件 Diff 保留原有关闭按钮。
- 远程图片保留下载及原有关闭入口。
- 远程文本原本由横条承担关闭功能；移除横条后，在标题栏右侧增加明确的 `×`
  关闭按钮，并保留下载按钮。
- 点击弹框外遮罩仍可关闭，底层会话滚动位置不变。

## 测试

- E2E 分别打开四类弹框，确认不存在 `.sheet-handle` 或
  `.sheet-handle-button`。
- 远程文本弹框必须存在可访问名称为“关闭远程文件”的标题栏按钮。
- 继续验证标题吸顶、内容滚动和页面无横向溢出。
