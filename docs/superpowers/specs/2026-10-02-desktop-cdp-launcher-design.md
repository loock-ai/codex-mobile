# 菜单栏启动器与 CDP 桥接

用户已确认执行：菜单栏应用；Codex 与 Dots 收发和审批；复用现有手机前端；启动器同时配置、启动原 app-server 模式。

采用 Electron Tray、React 面板、独立控制服务。原前端使用的 JSON-RPC 方法通过 CDP 适配真实桌面，不创建平行会话。桥接结果标记为 desktop-cdp，未支持的方法明确返回错误。旧 app-server 模式保持原行为。

CDP 仅连接本机，手机走口令鉴权网关。配置文件 0600；启动操作只使用固定程序和参数，不允许任意 shell。审批逐次核验且由用户明确选择；未知发送结果不得自动重放。重启只正常退出应用，不强杀，发现任务或草稿拒绝自动重启。

首版支持一个桌面窗口；通过版本化 DOM 适配读取当前会话、可见消息、控件。无法可靠识别时关闭写能力。Dots 无资格或未设置时显示不可用，不自动创建 Dot。完整历史、附件与语音不在首版。

交付实际 .app、运行说明、测试证据。真实桌面 CDP、双向消息、审批与手机联调的证据必须单独列出，不能用 fixture 代替。当前 Codex Desktop 承载本次实现会话，不能在工作中意外结束它。
